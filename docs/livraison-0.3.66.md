# Venator Ops 0.3.66 — identité dans l’extension

Venator Ops devient le nom affiché de l’extension, de ses commandes, de ses
fenêtres et de ses terminaux. Le mot-symbole reprend les visuels de référence,
avec OPS dans la couleur de la palette ; l’accueil présente le pentest dans
VS Code et l’IA à la demande. Les thèmes et les fonctions manuelles restent
disponibles.

Cette mise à jour conserve l’identité technique de l’extension et les données
existantes. Les titres Warband et Venator Ops sont reconnus pour les terminaux
déjà suivis, les créations en cours et le placement des fenêtres. Après une
réactivation, la restauration rouvre les shells selon le fonctionnement existant.
Les noms des fichiers VSIX restent donc `warband-0.3.66-…`.

Le README et les captures sont alignés sur l’interface. Le support des cours
reste limité au texte et à Markdown, sans lecture directe des PDF.

Livraison locale pour Windows x64 et Linux x64 : VSIX, empreintes, sources,
patch, vérifications et instructions ; brouillon GitHub sur le commit exact
et paquet privé dans le dossier Warband du Drive. Publication finale manuelle.
