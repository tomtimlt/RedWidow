# Venator Ops 0.3.65 — un README pour les utilisateurs

Le README du dépôt et celui embarqué dans les VSIX présentent maintenant Venator Ops, anciennement Warband, à travers les usages : cockpit, terminaux, agent optionnel, apprentissage, preuves et préparation du rapport. Les commandes restent nommées Warband dans l’extension actuelle.

L’installation part des VSIX prêts à l’emploi pour Windows x64 et Linux x64. Les premiers pas expliquent le projet, les conteneurs, la connexion facultative à un fournisseur et les mentions de terminal. Les formats de cours et de pièces jointes sont précisés : texte et Markdown, sans lecture directe de PDF. Les informations de compilation et d’architecture sont regroupées dans CONTRIBUTING.md.

Cette version change la documentation et le numéro de version, sans modification fonctionnelle ni renommage des identifiants de l’extension.

Livraison selon la pipeline permanente : vérifications existantes, compilation locale, deux VSIX et leurs empreintes, sources exactes, patch, brouillon GitHub sur le commit compilé et paquet privé dans Drive. La publication finale reste manuelle.
