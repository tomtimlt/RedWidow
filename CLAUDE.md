# Warband UI — atelier de présentation

@AGENTS.md
@DESIGN.md

Utiliser les vues et scénarios de démonstration existants pour travailler la
lisibilité, le graphisme, la navigation et l’accessibilité. Les actions sont
simulées localement ; les conserver ainsi.

Commencer par README.md. `npm run preview` lance l’aperçu du navigateur et F5
ouvre la fenêtre de développement VS Code. `npm run check` vérifie les sources
et les interactions simulées. Rapporter les fichiers modifiés et les vues
vérifiées, puis garder les changements de style faciles à reprendre.
