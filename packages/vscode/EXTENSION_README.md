# John

Chat d'agent avec approbation de chaque outil. Voir `docs/extension-vscode.md` du dépôt john-studio.

## Accès rapide (sans palette de commandes)

- **Barre d'état** : « 🚀 John » ouvre le lanceur ; l'élément du conteneur lié ouvre un terminal.
- **Barre de titre du chat** : terminal, nouveau chat, cockpit, réglages en un clic.
- **Raccourcis** (macOS : `Ctrl+J` au lieu de `Alt+J`) :

| Raccourci | Action |
| --- | --- |
| `Alt+J Alt+J` | Lanceur : fenêtres John et un terminal par conteneur démarré |
| `Alt+J T` | Terminal Exegol |
| `Alt+J C` | Chat latéral |
| `Alt+J N` | Nouveau chat dans l'éditeur |
| `Alt+J K` | Cockpit |
| `Alt+J M` | Monitor |
| `Alt+J S` | Réglages |

Jeton : « John : définir le jeton ».
